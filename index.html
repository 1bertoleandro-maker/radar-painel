Radar de Oportunidades

Este site (radar-painel) só exibe a tela. E-mails, Telegram, scores e VIP são gravados no repositório privado radar-precos/config_panel.json via API (precisa do PAT conectado).

Conectar Personal Access Token

O repositório de dados radar-precos é privado. Para carregar config_panel.json e docs/latest_deals.json, informe um GitHub Personal Access Token com permissão Contents: Read and write nesse repositório. O token fica apenas no localStorage deste navegador.

  1. GitHub → Settings → Developer settings → Personal access tokens
  2. Crie um token (classic repo ou fine-grained com Contents R/W em radar-precos)
  3. Cole abaixo e clique em Conectar e carregar
